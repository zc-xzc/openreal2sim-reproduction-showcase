# 项目概览

[返回首页](../README.md)

本项目将OpenReal2Sim固定来源、执行准备和验收拆成可审查步骤。重点是避免把模块能导入、服务能启动、输出文件存在或CPU测试通过，混同为GPU全流程完成。

上游算法包括深度估计、分割、背景补全、物体生成、配准、姿态优化及仿真相关功能；这些实现属于上游及各原作者。本包新增的是复现辅助工具、最小安全补丁、CPU合成测试和验收方法，不主张原创重建算法。

分别验收：环境部署；新输入单图的人工标注和全部重建阶段；视频时序/运动；模拟器内的真实物理任务。单图不证明视频，场景生成不证明策略训练。

先完成 [执行手册](execution-runbook.zh-CN.md) 的环境与模型闭合，再以合法新样本实测。现阶段没有本轮实测的耗时、显存下限、成功率、几何精度或训练收益。
