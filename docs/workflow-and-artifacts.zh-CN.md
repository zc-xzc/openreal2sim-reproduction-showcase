# 单样本流程与产物检查

[返回总览](../README.md)

本流程用于规划和记录复现，不是已验证的安装脚本。它不执行历史恢复命令，也不宣称所有上游版本的参数相同。请先固定实际 checkout，再查看该版本的说明、配置和命令行帮助。

## 1 登记输入和运行身份

给本次实验分配唯一 `run_id` 和样本 key，记录输入摘要、来源类型、许可状态、代码 commit、补丁、模型版本与环境。原文件名、个人目录、相册信息和精确位置不进入公开清单。

保留原输入，并为预处理结果使用新的输出位置。若该位置已存在，先判断是继续未完成运行还是新实验；不要以旧产物存在作为新运行成功证据。SHA256 可以帮助识别字节变化，但不能证明来源合法、输出真实或实验确实执行过。

## 2 先验收环境

先检查 GPU、CUDA、Python、图形运行时、模型文件和扩展，再进入模型计算。把检查运行与修复运行分开：验收中若缺依赖就判定失败，另开修复记录，不边修边宣布冷启动通过。

同时确认系统层和持久化数据层。模型缓存可见不等于扩展 ABI 兼容；虚拟环境能激活不等于系统动态库齐全；镜像名称一致也不等于镜像 digest 相同。

## 3 预处理

预处理通常准备图像、深度和相机参数等中间数据。对照代码使用 `--key_name` 参数；其他入口的参数可能不同，必须以实际版本为准。

最低检查包括：

- 本轮是否有明确开始/结束状态和退出码。
- 输入与输出 key 是否一致，文件时间与摘要是否对应本轮。
- 深度、图像尺寸和相机参数是否匹配，是否出现 NaN/Inf 或明显无效数值。
- 若数据需要反序列化，只处理可信来源的文件。不要读取陌生来源的 pickle。

## 4 人工标注

在受控网络内使用标注器。完成加载、点选、命名、确认、保存和重开检查，分别记录结果。不要只用 HTTP 可访问、进程存活或截图中出现窗口证明标注已完成。

- `ground` 应对应可解释的支撑面。
- 每个目标物体要有清楚的名称及掩码，检查边缘、漏分、误分和遮挡。
- 保存后重新载入，确认内容未丢失，且属于当前样本。
- 视频需要额外检查传播结果与跨帧身份，单图检查不能替代。

本案例的对照版标注器支持 `--key`，不是预处理入口的 `--key_name`。对照版 `--share` 的布尔解析也有使用风险，不能依靠传入字符串 `False` 判断已经关闭公开分享。

## 5 记录重建各阶段

下表列出应独立验收的8个重建阶段。本轮全部未在GPU运行。

| 阶段 | 作用 | 本轮状态 |
| --- | --- | --- |
| mask_propagation | 掩码处理与传播 | not_run |
| background_pixel_inpainting | 背景像素修复 | not_run |
| background_point_inpainting | 背景点云补全 | not_run |
| background_mesh_generation | 背景网格生成 | not_run |
| object_mesh_generation | 物体网格生成 | not_run |
| scenario_construction | 场景组装与ICP配准 | not_run |
| scenario_fdpose_optimization | FoundationPose姿态精修 | not_run |
| scenario_collision_optimization | 碰撞优化 | not_run |

执行时为每阶段记录 `completed`、`skipped`、`failed` 或 `not_run`，连同输入来源、退出码、耗时、跳过原因及输出摘要。`--stage` 的含义是从该阶段继续后续处理，不应默认它只执行一个阶段。

## 6 分层检查导出结果

以下是需要核验的产物类型，本候选不包含实际生成结果：

- `scene.json`：场景描述，通常需核对相机、物体列表、网格引用、地平面与包围盒。
- `scene_optimized.glb`：整体场景网格。
- `background_registered.glb`：背景相关网格。
- 物体网格与背景图像：需与场景中的引用一致。

检查至少分为四层：

1. **存在和可读。** 文件非空、格式能解析，引用的资产确实存在。
2. **结构一致。** 对象数量、名称、变换和网格引用相互匹配；明确缺失的 trajectory。
3. **几何合理。** 单位、尺度、坐标系、朝向和支撑面一致；检查穿透、漂浮、破碎网格和异常包围盒。
4. **下游可用。** 在指定模拟器中验证导入、碰撞、稳定性和目标交互。需要控制器或动作轨迹时另行验收。

文件尺寸大、渲染外观像输入图片或导入命令不报错，都不足以证明最后一层通过。没有轨迹时应标记不可用，不要补零或伪造动作标签。

可用[场景检查模板](../templates/scene-inspection.md)记录本轮实际覆盖的范围。
