# 批量图片准备与质量门禁

[返回总览](../README.md)

批量工作先解决输入管理，再逐步验证重建。自动评分可以减少人工浏览量，但不能保证图像符合三维重建假设，也不能替代 ground/object 标注。

## 当前范围

本候选不分发真实输入批次、原图、缩略图、逐图评分或重建结果。本轮已在私有原CSV上复算158条输入记录和20条候选的表内关联，公开[匿名聚合结果](input-record-validation.zh-CN.md)；以下仍是建议流程，不代表批次重建已执行。

## 建议的输入流程

```text
本地输入目录
  → 清单与缩略图
  → 技术质量检查
  → 内容与任务适配性人工复核
  → 少量候选复制到独立批次
  → 单个样本预处理
  → 人工确认并重开验证掩码
  → 重建与结果检查
  → 小批次扩展
```

复制与筛选时保留原输入。不覆盖既有实验，不根据文件名猜测内容，不把历史选中状态直接视为本轮批准。

## 第一关 技术质量

检查文件是否可解码、分辨率、模糊、过曝/欠曝、方向与重复内容。保留“拒绝”“需复核”“候选”及具体原因，而不是只有一个总分。

清晰度、亮度、边缘密度等指标受图像尺寸、纹理与材质影响。锐利的屏幕截图也可能不适合场景重建，低纹理的真实物体也可能被启发式错判。若没有固定公式、阈值、软件版本和人工标记，历史分数不可直接复现。

## 第二关 内容与任务适配性

逐图判断：主体是否明确、支撑面是否可见、边界与遮挡是否可处理、材质是否造成明显歧义、场景是否过于复杂。透明/强反光、细长、严重遮挡、非刚体或大量重复物体通常需要额外验证，不能一概认定可用或不可用。

单张图片无法完整观测背面几何。生成结果可能有合理外观但并不符合真实物体，尤其不能未经检查就当作精确物理资产。

图像启发式不等于重建成功概率。本候选只保留筛选框架，不包含候选原图、缩略图或个人路径。

## 第三关 单样本试运行

优先选择人工复核后最简单的一个样本，先完成预处理和标注，再进行重建。若失败，记录失败阶段与原因，不立刻批量提交其余样本。

单个样本通过后，用小批次覆盖不同主体、光照、背景与遮挡情况。每个样本独立记录环境版本、人工耗时、阶段状态、几何质量和仿真检查；不能只报告最好看的一个结果。

## 第四关 批次验收

统一定义成功标准后再统计：

- 计划、实际运行、完成、失败、跳过和未运行的样本数。
- 每阶段失败分布与人工复核量。
- 从原图到可读场景的完成率，以及另算的几何/仿真合格率。
- 运行耗时与人工耗时，区分首次下载、编译与稳定运行。
- 失败样本和参数变更，避免只保留成功记录。

只有筛选完成的样本不能进入重建成功率分子。缺少完整试验分母时不报成功率。

## 公开记录的最小字段

建议填写[批次记录模板](../templates/batch-input-record.json)。以匿名样本 ID 关联输入和运行，记录文件摘要、技术检查、人工复核、许可审查和运行状态。

私有原件和原路径仅在受控存储中保留。公开摘要不要包含人脸、EXIF 定位、原文件名中的个人信息、目录身份或私人分享链接。图片合法可读也不自动意味着允许上传、公开或训练使用。
